Network Protocols & Ports

Network protocols define how devices communicate across a network, while port numbers identify the services that receive and process network traffic.

NETWORK COMMUNICATION

Protocols Create Order

Every network device follows communication rules called protocols. These standards ensure that data is transmitted, received, and interpreted correctly regardless of the manufacturer.

Standard Rules Every device speaks the same language.
Reliable Communication Data reaches the correct destination.
OVERVIEW

Common Network Protocols

HTTP Web Pages
HTTPS Secure Web
FTP File Transfer
SSH Secure Remote Access
PROTOCOL

HTTP — Port 80

Hypertext Transfer Protocol delivers web pages between clients and web servers. HTTP traffic is transmitted without encryption.

Default Port: 80
SECURE PROTOCOL

HTTPS — Port 443

HTTPS protects web traffic using TLS encryption, providing confidentiality, integrity, and authentication.

Default Port: 443
FILE TRANSFER

FTP — Ports 20 & 21

File Transfer Protocol transfers files between systems. Traditional FTP does not encrypt traffic or credentials.

Uses Ports 20 (Data) and 21 (Control)
SECURE MANAGEMENT

SSH — Port 22

Secure Shell provides encrypted remote login and command-line access to network devices and Linux servers.

Default Port: 22
PORTS

What Is a Port Number?

IP Address

Identifies the destination computer or network device.

Port Number

Identifies the specific service or application running on that device.
