Network Infrastructure Devices

Learn how enterprise networking devices move, protect, monitor, and optimize data throughout modern computer networks.

NETWORK INFRASTRUCTURE

The Building Blocks of Every Network

Every network depends on specialized hardware to forward packets, connect devices, extend signals, provide wireless access, and protect information.

Connectivity Devices communicate efficiently.
Protection Secure and reliable networking.
LAYER 3

Router

Routers connect different networks together and determine the best path for forwarding packets between destinations.

Connects LANs to other networks and the Internet.
SWITCHING

Switch vs Hub

Switch

Uses MAC addresses to forward traffic only to the correct destination device.

Hub

Broadcasts every frame to every connected device regardless of destination.

SIGNAL DEVICES

Bridge vs Repeater

Bridge

Connects network segments while filtering traffic using MAC addresses.

Repeater

Regenerates weak signals to extend transmission distance.

INTERNET ACCESS

Modem

A modem converts digital signals into forms that can travel across an ISP's communication medium and back again, providing Internet connectivity.

Connects your network to your Internet Service Provider.
WIRELESS NETWORKING

Wireless Access Point (WAP)

A Wireless Access Point allows wireless devices to join a wired network, providing Wi-Fi connectivity for laptops, phones, and tablets.

Extends wireless network coverage.
NETWORK SECURITY

Firewall vs Load Balancer

Firewall

Filters network traffic using security rules to allow or block communications.

Load Balancer

Distributes client requests across multiple servers for improved performance.

THREAT PROTECTION

IDS vs IPS

IDS

Intrusion Detection System monitors traffic and generates alerts.

IPS

Intrusion Prevention System detects and blocks malicious traffic.

KEY IDEA Network infrastructure devices each perform a specialized role. Routers connect networks, switches intelligently forward frames, wireless access points provide Wi-Fi connectivity, firewalls protect traffic, load balancers improve availability, and IDS/IPS solutions monitor and defend enterprise networks.
