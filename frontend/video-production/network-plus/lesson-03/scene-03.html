Learn how email travels across networks, how users retrieve messages, and how administrators securely access remote systems.

COMMUNICATION SERVICES

Email & Remote Administration

Email protocols move messages between servers and users, while remote access protocols allow administrators to securely manage computers from anywhere.

Email Communication Reliable message delivery.
Remote Administration Manage systems securely.
EMAIL DELIVERY

SMTP

Simple Mail Transfer Protocol sends email from clients to mail servers and between mail servers.

Ports: 25, 587, 465 (Secure)
EMAIL RETRIEVAL

POP3 vs IMAP

POP3

Downloads email to one device. Port 110 Secure: 995

IMAP

Synchronizes email across multiple devices. Port 143 Secure: 993

REMOTE ACCESS

Telnet vs SSH

Telnet

Port 23 Sends credentials in plaintext.

SSH

Port 22 Encrypts all communication.

REMOTE DESKTOP

Remote Desktop Protocol (RDP)

Remote Desktop Protocol provides graphical remote access to Windows systems, allowing administrators to control computers over a network.

Default Port: 3389
SECURE CONNECTIVITY

Virtual Private Network (VPN)

A VPN creates an encrypted tunnel across an untrusted network, allowing users to securely access private resources from remote locations.

Protects data while traveling across the Internet.
