DNS, DHCP & NTP

Learn how DNS translates names, DHCP automatically assigns network settings, and NTP keeps systems synchronized with accurate time.

NETWORK SERVICES

Essential Infrastructure Services

Modern networks rely on infrastructure services that translate names, assign IP addresses, and synchronize system clocks automatically.

Automation Reduces manual configuration.
Reliability Keeps the network operating smoothly.
DNS

Domain Name System

DNS translates human- readable domain names into IP addresses that computers use to communicate.

Example: www.example.com → 93.184.216.34
DNS LOOKUPS

Forward vs Reverse Lookup

Forward Lookup

Converts a domain name into an IP address.

Reverse Lookup

Converts an IP address into a hostname.

DHCP

Dynamic Host Configuration Protocol

DHCP automatically assigns IP addresses, subnet masks, gateways, and DNS servers to network clients.

Eliminates manual IP configuration.
DHCP PROCESS

DORA Sequence

Discover Client searches for a DHCP server.
Offer Server offers an available IP address.
Request Client requests the offered configuration.
Acknowledge Server confirms the lease.
NTP

Network Time Protocol

NTP synchronizes clocks across network devices, ensuring accurate timestamps for logs, authentication, and troubleshooting.

Accurate time is essential for security and auditing.
