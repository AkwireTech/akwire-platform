NTP STRATUM NTP organizes time sources into hierarchical levels.
REFERENCE CLOCK Stratum 0
PRIMARY SERVER Stratum 1
DOWNSTREAM Stratum 2+
STRATUM NUMBER The number represents the server's distance in the synchronization hierarchy from the reference clock.

AUTHENTICATION Time-sensitive authentication systems depend on clocks being reasonably aligned.
