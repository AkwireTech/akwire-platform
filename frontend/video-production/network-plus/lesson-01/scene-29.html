PROMISCUOUS MODE Allows a network interface to process packets beyond traffic addressed only to that interface.
PORT MIRRORING A switch can copy traffic from selected interfaces to a monitoring port for packet capture and analysis.
ENCRYPTED TRAFFIC Packet headers can still reveal useful metadata even when the application payload is encrypted.
PCAP Captured packet data can be saved to a packet capture file for later inspection and analysis.

KEY IDEA Packet capture provides a detailed view of network communication. By examining addresses, ports, protocol fields, flags, timing, and payload information, administrators can locate problems that may not be visible from monitoring dashboards alone.
