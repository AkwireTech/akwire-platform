FIBER-OPTIC MEDIA

Data Travels as Light

Fiber-optic cabling carries network information using pulses of light instead of electrical signals.

High Bandwidth Supports high-speed links
Long Distance Extends beyond copper limits

ELECTROMAGNETIC INTERFERENCE
FIBER ADVANTAGE Immune to EMI

Because fiber carries light rather than electrical current, electromagnetic interference does not disrupt the signal.

TWO PRIMARY FIBER TYPES

Multimode and Single-Mode

MMF Multimode Fiber Larger core • Multiple light paths
SMF Single-Mode Fiber Smaller core • Single light path
