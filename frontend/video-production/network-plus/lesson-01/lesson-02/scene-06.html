LEGACY SECURITY

Wired Equivalent Privacy (WEP)

WEP was the original wireless security protocol, but weaknesses in its design allow attackers to recover encryption keys quickly.

Do not use WEP on modern networks.
IMPROVED SECURITY

Wi-Fi Protected Access (WPA)

WPA introduced TKIP to improve wireless security while remaining compatible with older hardware.

Better than WEP, but no longer recommended.
MODERN SECURITY

WPA2 with AES / CCMP

WPA2 replaced TKIP with AES encryption using CCMP, providing significantly stronger protection for wireless communications.

AES / CCMP became the enterprise standard for secure Wi-Fi.
LATEST GENERATION

WPA3 Security

WPA3 improves protection against password guessing attacks by using Simultaneous Authentication of Equals (SAE).

WPA3 is the preferred wireless security standard today.
AUTHENTICATION

Personal vs Enterprise

Personal (PSK)

Uses a single pre-shared key for all users.

Enterprise (802.1X)

Each user authenticates with unique credentials through a RADIUS server.
