ARP: IPv4 Address to MAC Address

Before an IPv4 packet can be delivered inside an Ethernet LAN, the sender may need to discover the Layer 2 MAC address of the next-hop device.

HOST A 192.168.1.10 AA:AA:AA:AA:AA:AA
SWITCH Layer 2
HOST B 192.168.1.20 BB:BB:BB:BB:BB:BB
HOST C 192.168.1.30 CC:CC:CC:CC:CC:CC
DEFAULT GATEWAY 192.168.1.1 11:11:11:11:11:11
REMOTE NETWORK Internet
HOST A WANTS TO SEND TO 192.168.1.20
Destination IPv4 address known But what is its MAC address?
STEP 1 Check ARP Cache

No entry for 192.168.1.20
ARP CACHE MISS MAC address is unknown
ARP REQUEST Ethernet Broadcast
