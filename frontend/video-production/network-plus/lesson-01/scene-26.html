SNMP VERSIONS Network+ expects you to recognize important security differences between SNMPv1, SNMPv2c, and SNMPv3.
SNMPv1 Legacy Community-string based
SNMPv2c Improved Operations Community-string based
SNMPv3 Security Features Authentication and privacy options
COMMUNITY STRINGS SNMPv1 and SNMPv2c use community strings for access control, but they do not provide the security capabilities available with SNMPv3.

KEY IDEA SNMP allows a management system to monitor devices through agents, MIBs, and OIDs. Normal SNMP queries use UDP 161, notifications are commonly received on UDP 162, and SNMPv3 provides stronger security capabilities than SNMPv1 or SNMPv2c.
