NETWORK MEDIA

Three Common Ways to Carry Network Traffic

ELECTRICAL

Copper

Uses electrical signals traveling through conductive copper wiring.

Common Example Twisted-pair Ethernet
LIGHT

Fiber Optic

Uses pulses of light traveling through glass or plastic fiber.

Common Use High-speed network links
RADIO

Wireless

Uses radio-frequency signals transmitted through the air.

Common Example Wi-Fi
COPPER MEDIA

Electrical Signals

Copper Ethernet represents binary data using electrical changes that travel through the cable.

FIBER-OPTIC MEDIA

Pulses of Light

Fiber carries data using light, allowing high-speed communication over longer distances while resisting electromagnetic interference.

WIRELESS MEDIA

Radio-Frequency Signals

Wireless networks transmit data through the air using radio waves instead of a physical cable between the communicating devices.
