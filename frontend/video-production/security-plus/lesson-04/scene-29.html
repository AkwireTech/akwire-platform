Data Classification & Handling

Data classification helps organizations identify how sensitive information is and determine the controls required to protect it.

THE SECURITY PROBLEM

Not all data requires the same protection

Organizations classify information according to its sensitivity, business value, and potential impact if it is exposed, changed, or destroyed.

DATA CLASSIFICATION Apply a classification that matches the sensitivity
Public Information approved for public access.
Internal Information intended for authorized personnel.
Confidential Sensitive information requiring stronger controls.
Restricted Highly sensitive information with strict access.
DATA HANDLING Classification should guide how data is handled
01 Classify Identify the sensitivity of the information.
02 Label Mark the data according to policy.
03 Protect Apply controls based on sensitivity.
04 Dispose Securely remove data when retention ends.
PROTECTION REQUIREMENTS More sensitive data requires stronger handling controls
Access Control Limit access to authorized users.
Encryption Protect sensitive data from unauthorized disclosure.
Monitoring Detect inappropriate access or handling.
The classification determines the handling requirements.
SECURITY IMPACT Classification reduces inconsistent data handling
WITHOUT CLASSIFICATION Data may receive inconsistent protection Employees may not know which controls or handling procedures are required.
WITH CLASSIFICATION Handling requirements become clearer Classification helps users apply the appropriate security controls and procedures.
SECURITY+ PRACTICE Think about the data before choosing the control
01 Identify What type of information is being handled?
02 Classify How sensitive is the information?
03 Protect Which controls are required by policy?
04 Handle Follow the approved handling procedures.
EXAM MEMORY

Classify first. Protect according to sensitivity.

Data classification helps determine how information should be accessed, stored, transmitted, monitored, retained, and disposed of.

SCENE SUMMARY Four ideas to remember
Classify data according to sensitivity.
Label data according to organizational policy.
Apply controls that match the classification.
Dispose of data securely when it is no longer required.
KEY CONCEPT

Data classification connects information sensitivity to security controls.

When organizations understand what data they have and how sensitive it is, they can establish consistent requirements for protecting and handling that information.
