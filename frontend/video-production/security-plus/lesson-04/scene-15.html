Public Key Infrastructure (PKI)

Public Key Infrastructure establishes trust by using digital certificates, certificate authorities, and defined validation processes to connect identities with public keys.

THE TRUST PROBLEM

PKI establishes trust

Public Key Infrastructure provides a framework for associating identities with public keys and establishing trust through digital certificates and trusted authorities.

PKI COMPONENTS Each component supports the trust model
Certificate Authority Issues and signs digital certificates.
Registration Authority Helps validate certificate requests and identities.
Digital Certificate Binds an identity to a public key.
Certificate Repository Provides access to certificate information.
CERTIFICATE LIFECYCLE Certificates move through defined stages
Request Certificate request is submitted.
Validate Identity and request are verified.
Issue The CA signs and issues the certificate.
Renew / Revoke Certificate status is maintained throughout its life.
CERTIFICATE TRUST CHAIN Trust flows from the root to the endpoint
END ENTITY User / Server
INTERMEDIATE CA Delegated Trust
ROOT CA Trusted Anchor
If the certificate chain leads to a trusted root, the identity can be trusted.
CERTIFICATE REVOCATION Check whether a certificate is still trusted
CRL Certificate Revocation List A published list of certificates that have been revoked.
VS
OCSP Online Certificate Status Protocol Checks certificate status through an online responder.
PKI IN PRACTICE Where certificate-based trust is commonly used
TLS Establishes trusted encrypted connections.
Secure Email Certificates can support signing and encryption.
Authentication Certificates can identify users and systems.
Device Trust Certificates can establish trust for devices.
EXAM MEMORY

CA issues. Certificate binds. Chain establishes trust.

A digital certificate associates an identity with a public key. The certificate authority establishes trust by signing the certificate. A certificate chain connects the endpoint to a trusted root CA.

SCENE SUMMARY Four PKI ideas to remember
Certificates bind identities to public keys.
Certificate authorities establish trust.
Certificate chains lead toward a trusted root.
CRL and OCSP help determine certificate status.
KEY CONCEPT

PKI creates a framework for trusted digital identities.

Certificates connect identities to public keys, certificate authorities establish trust, and validation mechanisms help determine whether that trust should still be accepted.
