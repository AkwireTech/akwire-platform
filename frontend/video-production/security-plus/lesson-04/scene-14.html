Cryptographic Algorithms & Key Management

Cryptographic security depends not only on encryption, but also on choosing appropriate algorithms and protecting the keys that control access to encrypted information.

THE CRYPTOGRAPHIC DECISION

Strong algorithms are only part of the solution

A cryptographic system is only as secure as the algorithms, keys, and processes used to protect it. Understanding the role of each component is critical.

COMMON CRYPTOGRAPHIC FUNCTIONS Different algorithms solve different problems
Encryption Protects confidentiality by transforming readable data into ciphertext.
Hashing Produces a fixed-length value used to detect changes in data.
Digital Signatures Support authenticity, integrity, and non-repudiation.
Key Exchange Establishes cryptographic material between communicating parties.
KEY MANAGEMENT Protect the keys that protect the data
Generate Create strong cryptographic keys.
Store Protect keys from unauthorized access.
Use Apply keys only for authorized cryptographic operations.
Rotate Replace keys according to security requirements.
KEY PROTECTION A stolen key can defeat strong encryption
Encrypted Data Confidential information remains protected by cryptographic controls.
Protected Key Access to the key must be restricted and controlled.
Protecting encrypted data without protecting its keys leaves the security boundary exposed.
ALGORITHM SELECTION Symmetric and asymmetric cryptography
Symmetric

Uses the same shared secret key to encrypt and decrypt data.

Efficient for bulk data
VS
Asymmetric

Uses a related public and private key pair for cryptographic operations.

Useful for identity and key exchange
SECURITY PRACTICE Apply cryptography as part of a complete control
01 Choose appropriate algorithms Match the cryptographic function to the security requirement.
02 Protect cryptographic keys Restrict access and manage the full key lifecycle.
03 Manage the lifecycle Generate, store, use, rotate, and retire keys appropriately.
04 Follow security policy Cryptographic controls must support organizational requirements.
EXAM MEMORY

Strong cryptography still depends on strong key management.

Know what the algorithm protects, what the key controls, and how the key is managed throughout its lifecycle.

SCENE SUMMARY Four ideas to remember
01 Cryptographic Functions Encryption, hashing, signatures, and key exchange solve different security problems.
02 Key Management Keys must be generated, stored, used, rotated, and retired securely.
03 Key Protection Strong encryption cannot compensate for exposed cryptographic keys.
04 Algorithm Selection Choose the cryptographic approach that matches the security requirement.
AKWIRE SECURITY+ CORE CONCEPT

Cryptography protects the data. Key management protects the cryptography.
