Cryptography — Scenario Analysis

Security+ scenarios require you to identify the security requirement, recognize the cryptographic technology involved, and determine how the technology should be applied.

SCENARIO ANALYSIS

Start with the security requirement

Before selecting a cryptographic technology, determine what the organization needs to protect and what security property the solution must provide.

COMMON SCENARIOS Recognize the requirement before selecting the control
Protect Data Use encryption when information must remain confidential.
Verify Integrity Use hashing to detect changes to data.
Establish Identity Use certificates and PKI to support trusted identities.
Secure Communication Use secure protocols to protect network communications.
DECISION PROCESS Follow the requirement from beginning to solution
Requirement What needs protection?
Objective What security property is needed?
Technology Which cryptographic control fits?
Implementation How should it be securely deployed?
TECHNOLOGY MATCHING Connect common requirements to cryptographic controls
SENSITIVE DATA Encryption
TRUSTED IDENTITY Certificate
SECURE SESSION TLS
The correct answer is usually the control that directly satisfies the requirement described in the scenario.
THREAT PERSPECTIVE Ask how cryptographic weaknesses could be exploited
WEAKNESS Exposed Protection Weak algorithms, poor key management, expired certificates, or outdated protocols can reduce protection.
VS
DEFENSE Managed Protection Strong algorithms, protected keys, valid certificates, secure protocols, and lifecycle management improve protection.
SCENARIO CHECKLIST Use four questions to break down a Security+ scenario
What? What information or communication needs protection?
Why? What security objective must be achieved?
Which? Which cryptographic technology satisfies the objective?
How? How should the technology be implemented and maintained?
EXAM MEMORY

Read the requirement before reading the technology.

Security+ scenarios often provide several technologies that sound correct. Focus first on the security objective, then eliminate controls that do not directly satisfy it.

SCENARIO SUMMARY Analyze the requirement before selecting the solution
Identify the information or communication that needs protection.
Determine the security objective.
Select the cryptographic mechanism that fits the requirement.
Consider implementation, key management, and lifecycle.
LESSON 03 — SCENARIO TAKEAWAY

Match the cryptographic control to the security requirement.

When analyzing a Security+ scenario, identify the requirement, determine the security objective, select the appropriate cryptographic mechanism, and evaluate how it must be implemented and maintained.
