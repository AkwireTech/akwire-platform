Cryptographic Fundamentals

Cryptography protects information by transforming data so unauthorized users cannot read, alter, or reliably impersonate trusted communications.

THE SECURITY PROBLEM

Data must remain trustworthy

Cryptography provides mechanisms for protecting confidentiality, integrity, authenticity, and trust. Different cryptographic functions solve different security problems.

WHAT CRYPTOGRAPHY PROVIDES Match the mechanism to the security goal
Confidentiality Prevent unauthorized parties from reading data.
Integrity Detect whether data has been changed.
Authenticity Establish confidence in an identity or source.
Non-repudiation Provide evidence supporting who performed an action or approved data.

Asymmetric cryptography uses related key pairs and supports functions such as secure key exchange and digital signatures.

Hashing is commonly used to verify integrity and support password-protection mechanisms. A hash function is designed to produce a one-way digest rather than readable ciphertext that can simply be decrypted.

SECURITY SCENARIO Which mechanism fits the requirement?
REQUIREMENT Protect sensitive stored data

An organization needs to prevent unauthorized users from reading confidential information.

CONTROL Encryption

Use encryption to provide confidentiality for the protected data.

EXAM MEMORY

Encrypt for confidentiality. Hash for integrity.

Symmetric encryption uses a shared secret key. Asymmetric cryptography uses a public/private key pair. Hashing creates a digest and is not the same thing as encryption.

SCENE SUMMARY Cryptography uses different mechanisms for different goals
Encryption protects confidentiality.
Symmetric uses one shared secret key.
Asymmetric uses public/private keys.
Hashing produces a digest for integrity-related uses.
KEY CONCEPT

Choose the cryptographic mechanism that matches the security goal.

Encryption, asymmetric cryptography, hashing, and digital signatures solve different problems. Understanding the distinction is essential for Security+.
