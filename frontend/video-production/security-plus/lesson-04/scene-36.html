Backup Storage & Retention

ACT 01 • STORAGE & RETENTION

Backup copies need the right storage strategy

Backup protection depends on where copies are stored, how long they are retained, and how securely they can be accessed or restored.

ACT 02 • STORAGE OPTIONS

Backups can be stored in different locations

On-Site Stored at the organization's primary location
Off-Site Stored at a separate physical location
Cloud Stored through a remote cloud service
Isolated Separated from normal production systems
ACT 03 • RETENTION LIFECYCLE

Retention determines how long backup copies remain available

01
Create Generate backup copies
02

03

ACT 04 • RETENTION CONTROLS

Retention policies help control backup storage

Retention Policy Defines how long backup copies must be kept.
Backup Schedule Determines when backup copies are created.
Secure Disposal Removes expired copies according to policy.
Retention requirements should support business, legal, regulatory, and recovery needs.
ACT 05 • STORAGE RISK

Backup location affects recovery resilience

Single Location If the backup and production systems are affected by the same disaster, recovery may also be lost.
Distributed Storage Separate storage locations reduce the chance that one event destroys both production and backup data.
ACT 06 • PRACTICE

Security+ backup storage reminders

01 Separate backup copies from production systems
02 Use off-site or cloud storage when appropriate
03 Define and enforce retention requirements
04 Securely dispose of expired backup copies
EXAM MEMORY

Store backups separately and retain them appropriately

Backup storage should protect copies from the same threats that could affect production systems.

SCENE SUMMARY

What you should remember

Backup copies can be stored on-site, off-site, in the cloud, or in isolated environments.
Separating backup storage from production systems improves resilience.
Retention policies define how long backup copies should remain available.
Expired backup data should be securely disposed of according to policy.
FINAL CONCEPT

Protect the backup from the same disaster

A strong backup strategy uses appropriate storage locations and retention policies so recovery data remains available when it is needed.
