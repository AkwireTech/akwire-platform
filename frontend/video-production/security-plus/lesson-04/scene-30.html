Data Protection Controls

Data protection controls reduce the risk of unauthorized access, disclosure, alteration, loss, and improper handling throughout the information lifecycle.

ACT 01 • PROTECTION

Sensitive data needs layered protection

Organizations use multiple controls to protect information from the moment it is created until it is securely destroyed.

ACT 02 • CORE CONTROLS Different controls protect data in different ways
Access Control Limits who can access sensitive information.
Encryption Protects data by making it unreadable without the required key.
Backups Preserve information so it can be restored after loss or damage.
Monitoring Detects suspicious access and unusual activity involving protected data.
ACT 03 • DATA LIFECYCLE Protection must continue throughout the data lifecycle
Create Establish the data and its classification.
Use Allow authorized users to access the data.
Store Apply appropriate physical and technical controls.
Dispose Destroy information securely when no longer needed.
ACT 04 • DATA STATES Data requires protection in different states
DATA AT REST Stored Data
DATA IN TRANSIT Moving Data
DATA IN USE Active Data
The protection method should match how and where the data is being used.
ACT 05 • RISK REDUCTION Weak controls increase exposure
WEAK PROTECTION Greater Exposure Excessive access, weak storage controls, and poor disposal increase data risk.
STRONG PROTECTION Reduced Exposure Least privilege, encryption, monitoring, backups, and secure disposal reduce risk.
ACT 06 • PRACTICAL APPLICATION Key protection practices
Least Privilege Give users only the access they need.
Encrypt Data Protect sensitive information from unauthorized disclosure.
Maintain Backups Keep recoverable copies of important information.
Secure Disposal Destroy data so it cannot be recovered improperly.
SECURITY+ EXAM MEMORY

Protect the data — not just the device.

When a question describes sensitive information, think about access, encryption, storage, monitoring, backup, retention, and secure disposal.

ACT 08 • SCENE SUMMARY Data protection is a layered process
Control access to sensitive data.
Encrypt data when appropriate.
Maintain recoverable backups.
Dispose of data securely.
FINAL CONCEPT

Data protection follows the information.

From creation and use to storage and disposal, security controls should protect information according to its sensitivity, state, and risk.
