Security Controls & Defense in Depth

Understand how organizations use administrative, technical, physical, and operational controls to reduce security risk.

Security Fundamentals
SECURITY CONTROLS

Reduce Risk with Controls

Security controls are safeguards designed to protect systems, information, people, and organizational operations. Controls can prevent attacks, detect suspicious activity, correct problems, or reduce the impact of an incident.

Protect Reduce the likelihood or impact of security events.
Layer Security Use multiple safeguards instead of relying on one.
SECURITY CONTROLS

Four Major Control Categories

Administrative

Controls based on policies, procedures, standards, training, and organizational requirements.

EXAMPLE Security policy
Technical

Technology-based safeguards that protect systems, networks, applications, and data.

EXAMPLE Firewall
Physical

Controls that protect facilities, equipment, and physical resources.

EXAMPLE Door access control
CONTROL FUNCTION

Preventive Controls

Preventive controls are designed to stop an unwanted event before it occurs. They reduce the likelihood that a threat will successfully exploit a weakness.

Examples include access controls, security awareness training, firewalls, and physical barriers.
CONTROL FUNCTION

Detect, Correct & Recover

Detective

Identify or discover unwanted activity after or while it occurs.

EXAMPLE IDS alert
Corrective

Reduce the effect of an incident and restore systems to an expected state.

EXAMPLE Restoring a system
Recovery

Return operations to normal after a disruptive security event.

EXAMPLE Backup restoration
SECURITY STRATEGY

Defense in Depth

Defense in depth uses multiple layers of security controls so that the failure of one safeguard does not automatically result in a successful compromise.

Example: physical security + authentication + firewall + endpoint protection + monitoring.
SECURITY DESIGN

Compensating Controls

A compensating control is an alternative safeguard used when the preferred security control cannot be implemented as intended.

The alternative should provide an appropriate level of protection for the identified risk.
MEMORY CHECK

Control Strategy

PREVENT Stop the event
DETECT Identify the event
CORRECT Reduce the impact
RECOVER Restore operations
PREVENT Stop unwanted activity
DETECT Find suspicious activity
DEFEND Use multiple layers
KEY TAKEAWAY Security controls reduce risk by preventing, detecting, correcting, or recovering from unwanted events. Strong security programs combine different control types and layers of protection so that one failed safeguard does not automatically expose the entire environment.
