Authentication & Identity

Learn how security systems establish identity, verify users, and strengthen authentication with multiple factors.

Identity & Access Management
IDENTITY

Who Are You?

Authentication is the process of verifying that a claimed identity actually belongs to the person, device, or service requesting access.

Identification A subject claims an identity.
Authentication The claimed identity is verified.
AUTHENTICATION FACTORS

What You Know, Have, or Are

Something You Know

Information that only the user should know.

EXAMPLES Password • PIN
Something You Have

A physical object or device controlled by the user.

EXAMPLES Security token • Phone
Something You Are

A physical or behavioral characteristic of the user.

EXAMPLES Fingerprint • Face
MULTIFACTOR AUTHENTICATION

MFA

Multifactor authentication requires authentication factors from two or more different factor categories. Using multiple factors makes account compromise more difficult when one factor is stolen.

Example: password + authenticator application or security key.
CREDENTIAL SECURITY

Password Security

Length

Longer passwords or passphrases generally provide stronger resistance to guessing.

Unique

Avoid reusing credentials across different services.

Password Manager

Password managers can help create and store unique credentials securely.

BIOMETRICS

Something You Are

Biometric authentication uses measurable characteristics of a person to help establish or verify identity.

Examples include fingerprints, facial recognition, iris characteristics, and voice characteristics.
IMPORTANT DISTINCTION

Authentication vs Authorization

Authentication

Answers: “Who are you?”

EXAMPLE Login verification
Authorization

Answers: “What are you allowed to do?”

EXAMPLE File permissions
Accountability

Actions can be associated with an identified subject through logging and monitoring.

MEMORY CHECK

Authentication Factors

KNOW Password or PIN
HAVE Token or device
ARE Biometric
MFA Two or more categories
KNOW Password or PIN
HAVE Device or token
ARE Biometric characteristic
KEY TAKEAWAY Identification claims an identity. Authentication verifies that identity. Authorization determines what the authenticated subject can access or do. Strong authentication can use multiple factor categories, such as something you know, something you have, and something you are.
